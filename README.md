# Fake News Detector

## Overview

Fake News Detector is a Flask-based web application that uses Machine Learning to analyze news content and classify it as Real or Fake.

The project aims to help users verify news articles quickly through a simple and user-friendly interface.

---

## Features

- Fake News Detection
- Machine Learning Based Prediction
- Fast and Accurate Results
- User-Friendly Interface
- Flask Web Application
- Real-Time Analysis

---

## Technologies Used

- Python
- Flask
- HTML
- CSS

- Pandas
- NumPy

## APIs

This project currently uses a Machine Learning model for prediction and does not require any external API.

## Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/Fake-News-Detector.git
```

### Move into Project Directory

```bash
cd Fake-News-Detector
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python app.py
```

### Open in Browser

```bash
http://127.0.0.1:5000
```

---

## Usage

1. Open the application.
2. Enter the news content.
3. Click the Predict button.
4. View the prediction result.
